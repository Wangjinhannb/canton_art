# WANXIANG V4

湾区万象 V4：粤港澳大湾区大学生艺术节数智创新类交互作品。

当前 V4 先把 **佛山醒狮** 一幕作为全项目视觉质量基准：真实材质分层、受限摄影机、鼓点驱动的分部件运动、竹篾骨架观察模式，以及克制的当代东方 UI。

## Run

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## V4 quality gate

- 静止截图本身必须成立，不靠交互掩盖粗糙画面。
- 不使用百分比、任务条、大段诗性说明和通用黑金模板。
- 纸扎、漆面、金饰、眼球、绒毛、竹篾分别使用不同材质逻辑。
- 鼠标移动只产生轻微空间视差；拖动才扩大观察范围，并始终限制在最佳构图附近。
- 鼓点不会让整个模型一起缩放，而是眼、眉、下颌、耳、头部、鬃毛分层响应。
- 后处理仅作为收尾：ACES + SMAA + 极轻 Bloom。

## Cultural boundary

V4 是依据佛山狮头彩扎工艺结构进行的原创数字艺术转译，不宣称是某一件历史狮头的精确数字复原。正式参赛前仍需对选定狮种的额纹、眉眼、角型、配色和装饰进行进一步人工核验。

## Controls

- Pointer move：轻微空间视差
- Drag：受限观察角度
- Click / Space：鼓点唤醒
- G：切换竹篾骨架观察模式
- D：开发调参面板
